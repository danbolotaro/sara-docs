SARA

Sistema de Apoio e Registro de Acolhimento

O SARA é uma aplicação web para registrar pessoas acolhidas e os encontros feitos com cada uma delas. A ideia é simples: manter num só lugar quem é a pessoa, um pouco da sua história, e o histórico de conversas, pedidos de oração e anotações de cada visita.

Esta página reúne a documentação do projeto: o que o sistema faz, como rodar localmente e os diagramas usados na modelagem.

Por onde começar

  • O sistema — funcionalidades, telas, API e dados.
  • Instalação — requisitos, configuração do Supabase e como executar.
  • Diagramas — caso de uso, DER e diagrama de classes.
